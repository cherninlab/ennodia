# Ennodia 0.5.0

Release scope for 9 November 2026.

## Core

- Installation evidence identifies runtime, package, and storage limitations.
- Readiness preflight checks selected routes before orchestration. Native
  recovery distinguishes sign-in, expired keys, unavailable models, and quota.
- `ennodia_setup` shows agent status and recovery steps. Compatible hosts show
  a setup card. Other hosts receive the Markdown panel.
- Comparison results and history carry attributed “Keep in mind” notes,
  with evidence and uncertainty kept separate from the chosen answer.
- The npm launcher rejects unsupported Bun runtimes. Packaged installation
  checks cover the new runtime files.

## Website and publishing

The website includes conversation examples and refined landing-page controls.
New npm releases include provenance. GitHub Actions use updated pinned versions.
The Astro and Starlight major migration is tracked separately in
[issue 24](https://github.com/cherninlab/ennodia/issues/24).

## Validation and limits

The release gates are `bun run release:check`, including the full verification
suite, npm and JSR dry-runs, and real packed-package MCP handshakes through
`bunx`, `npm exec`, and `npx`. Registry publication and website deployment must
also succeed in their separate GitHub Actions workflows.

Mobile source is included in `apps/mobile` as the separate `0.1.0+1` development
project. Analysis and all 18 Flutter tests passed on 9 November. Native builds,
assistant connections, and store releases remain unavailable or unverified.
Mobile is excluded from the npm and JSR packages.

Private benchmark material remains local. No new benchmark-quality or savings
claim is part of this release. Release checks do not prove access to every
provider account or model.
