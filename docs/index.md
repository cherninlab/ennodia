# Keep your agent. Get another way forward.

Ennodia lets your primary artificial intelligence (AI) agent try another agent, model, or skill on a focused task.
The findings return to your existing conversation.

You can explore another explanation for a bug, test a skill, or examine conflicting advice.
Your primary agent keeps responsibility for checking and integrating the result.
Even an unsuccessful attempt can show which approach was tested under the recorded conditions.

## Your existing tools

Ennodia runs as a local Model Context Protocol (MCP) server.
It connects to supported installed agents through their public command-line interfaces (CLIs).
Your configured providers supply the models. Existing subscriptions, usage limits, and permissions still apply.

Ennodia discovers native Agent Skills and can request a skill for a separate task.
A native agent can also choose unrequested skills from its environment.
